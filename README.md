# TriWallet MVP

A polished Expo/React Native prototype for a Nigerian consumer wallet featuring:
- Naira send/receive and indicative USD/GBP views
- Bills, airtime, AI merchant subscriptions, Cowry, rail, NGX watchlist, savings and loans
- Security-centre UX and recent transactions

## Run
1. Install Node.js 20+
2. `npm install`
3. `npm start`
4. Open with Expo Go or an emulator

## Important
This is a front-end MVP using demo data. It does not move money. Do not ship the hard-coded demo FX rates. Production requires licensed financial partners, legal review, live integrations, reconciliation, fraud controls, KYC/AML and independent security testing.
